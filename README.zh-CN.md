# Weftext

当前开发树已整合 v0.7 的既有开发切片：GUI／CLI 双入口、碎片与提醒消费者、界面语言及平台宿主基础，并统一保存／原操作交付和 Draft 基线恢复。合并开发切片的验证范围按 WORKFLOW 记录，不代表整版 v0.7 完成。Windows 原生窗口与安装交付、完整 Linux／Android／Apple 产品、真实 IME／辅助技术及性能／识别平台矩阵仍按 ROADMAP 独立验收；0.6.3 原有未验项保留。

基于原生 Typst 的文件型知识与写作工具。当前 **0.6.0 Windows／NTFS 既定 v0.6 范围已完成并通过最终优化程序验收，尚未正式发布**。本地与受控 Server / WebUI、多用户权限和同所有者同步包括部分副本、复杂结构组合、原生语义复验及资源退役保全。旧原型已归档，不是当前构建依赖。

同一最终优化程序已通过完整 HTTP 矩阵、受影响浏览器与真实 NAS HTTPS 验收，保留原物理身份、个人 Draft／Undo、独立权限及原操作恢复边界。支持范围和仍未验的平台条件见 [MVP](docs/MVP.zh-CN.md)；Windows／NTFS 与 NAS 客户端结果不外推其他 OS、真实系统 IME、完整辅助技术或实际断电。

此前交付的 **0.6.2 本地交付候选，初始 Windows 本地／自托管识别范围已完成**：PDF 文本层、PNG／JPEG OCR、首批大陆公文和数电普通发票方案，接入原件对照、字段确认及 Core 原子导入。识别运行时须独立显式安装；图片低可信与复杂版式保留部分状态和损失，具体支持表及验收边界见 [MVP](docs/MVP.zh-CN.md)。0.6.1 最终候选的真实系统输入法复验及原一次撤销异常仍有证据限制。Obsidian／参照插件只用于独立交互设计对照，不是 Weftext 的运行依赖，也不与其资料库联动。

此前 **0.6.3-rc.4 发布候选的整版验收尚未完成**。保留前三阶段的导航／写作、属性／Query、普通根预设、链接诊断和稳定片段候选，并接通多级标签、二维关系图谱、独立只读标题结构、作者同级顺序及按需媒体缩略图；具体范围和限制见 [MVP](docs/MVP.zh-CN.md)。实现与定向检查不代表整版 0.6.3 完成，也不代表已公开发布。

本轮继续收口托管面板连接：独立面板失败会分别报告，后续获权入口继续初始化；身份或授权变化仍停止旧连接。历史输入法、撤销及整版对照／性能限制继续保留，不把连接故障隔离称作原超时根因已确定。

2026-10-20 定版的[多级标签设计](docs/REQUIREMENTS.zh-CN.md#511-多级标签)已接入 Core v2 森林、精确／含子级 Query、独立移动授权、统一选择器及同步／原生包消费者。原 alpha.3 的扁平标签结论保留为旧候选事实；本轮须在同一最终候选完成 TAG01–10／UX01–12 的实际验收，真实旧资料转换及历史输入法／撤销限制不会由实现自动闭环。

## 本地检查

Python 3.11 或更新版本，无额外 Python 包：

```text
python scripts/check.py --models
```

默认检查当前文档的文件链接、双语配对、JSON 与需求库存；`--models` 在临时副本运行有限设计模型，不改已记录证据。官方 Typst 编译与平台原型按各自 README 手动复现，不在每次纯文字修改时重复构建。

历史原型、旧设计和完整评审可从归档恢复，但不是当前构建依赖。当前合同变化需同步相关消费者与双语文档。尚未交付的软件不能因文档检查通过而标为可用。
