# Security policy

Weftext is pre-release software and has no supported production version.

For a suspected vulnerability, do not disclose exploitable details in a public issue. Use GitHub private vulnerability reporting when it is enabled. If it is unavailable, open a public issue that asks only for a private maintainer contact; include no secret, user document, personal path, token, or exploit detail.

Supported versions and response targets will be defined before the first public release. Dependency advisories, packaged binaries, update signing, Server authentication, authorization, backup recovery, and model/artifact provenance are release gates.
