# Weftext Engine

原生 Typst 编译与保守的作者源码投影。产品解释使用唯一目录生成的 `UiMessage`；Typst、操作系统和依赖的真实诊断保留来源及原文。界面语言不进入作者源码或机器准入判定。

`Diagnostic` 分开保存可选的产品解释、原始诊断和准确的来源位置。固定版本原生 HTML 适配器直接产生带编译器位置的封闭警告事实，作者 HTML 属性不能伪造这些事实。每个 `LocalWorld` 独立记录依赖准入事实，与编译器诊断分开；分页与流式输出均保留两个通道。

`EngineError` 使用明确的显示树预算变体，并保留类型化主要解释及完整并列产品诊断。`into_parts` 在 Core／API／worker／Data 桥中保全并列诊断，不挤入有界因果链；附加证据不会改变显示树预算的机器类别。

测试覆盖真实原生编译、原诊断与源码位置往返、类型化原生警告、每次编译独立的依赖预算、预算与并列证据共存及源码编辑。使用产品仓库检查入口与已获授权的共享构建目录验证。
