# 知识功能算法

本 crate 只处理 Core 已限定并冻结的可读快照，不读取或写入文件，不分配身份，也不自行授予权限。Core 负责当前文件代次、读取资格、操作 ID、完整选择闭包、精确前后镜像以及逻辑事务。快照中的 `coverage` 只描述获准范围；部分结果不能证明整个资料库不存在链接或候选。

- [关系诊断](src/diagnostics.rs)：复用同一获权快照按原生逐处引用报告问题，并独立列属性字段问题；不为字段伪造正文位置。节点连接与内部片段状态分开，无效出链与部分扫描不冒真正孤立；预算覆盖整个声明范围，不按节点重新放大。个人忽略及预期孤立只由前端过滤，不改变此纯投影。
- [链接](src/links.rs)：官方 Typst AST 与标准绑定证明枚举原生链接、文内标签和引用。未证明或被遮蔽的 `link` 调用不进入真实链接索引。ID 与当前路径入链分组；属性引用另列。笔记与已有资源均支持四种地址转换；资源库路径由真实平台文件路径及已准入笔记的库内路径共同限定，不猜文件名。转换重新解析并核对相同目标，保留原片段拼写、显示文字和未选字节；没有显式正文的链接通过同一个调用补丁保留旧显示文字。
- [潜在链接](src/mentions.rs)：针对同一个授权词典执行精确 Unicode 重叠扫描；保留同位置多目标、嵌套及交叉范围。两条显示通道之外的候选仍在完整列表中。范围显式携带 UTF-8 与 UTF-16 坐标；部分字素、过期词典或没有唯一编辑映射的发现不可快捷改写。编译树中的独立逻辑片段不会被拼接。标量、候选数量或输出预算到达时明确返回部分覆盖和实际停止位置，不截断同位置目标集合。
- [批注](src/annotations.rs)：独立 JSON 保存讨论、回复、状态及历史目标。重复 JSON 成员、损坏文件和未知格式不会变成空文件。无效目标仍能保留讨论并解决／重新打开；保守恢复仅供读取。默认批注投影不返回源码前像、私密 URI、原始范围或新目标上下文。跨版本定位需要逐步验证的完整精确编辑链；相似文字不产生自动重定位。建议只使用已证明的普通文字槽，并生成源码与接受状态的两份前后镜像；重新确认是独立明确操作。
- [模板与复制](src/copy.rs)：可复用模板登记引用原生笔记的精确身份和修订，不另存一份权威源码；修订改变须重新登记。参数槽由官方 AST 或可写文字映射证明，禁止覆盖管理身份／类型控制；参数按精确槽写入原生字面量，缺失、默认值与显式 null 分开。复制使用 Core 一次提供的有序身份／资源／批注／定义／候选版本映射；只改官方 AST 和已安装 schema 指定的槽，不改普通文字、电话号码或 CEL 字符串。保存查询的调用和范围引用先经数据引擎限定完整原生角色，再绑定实际 AST 控制槽。current 定义引用跟随同一复制映射；pinned 保留原 owner/key/revision，并列出历史外部依赖。无法证明的引用或批注定位会拒绝完整复制，或返回明确损失及必须保存的原件。

`NodeSnapshot.path` 是平台产生的规范本机文件 URL；`PlannedFile.path` 是宿主提供的真实安装目标。宿主在这两个边界转换路径，并重新验证当前权限。`SourcePatch` 和任何字符串身份均不是写权限。

现阶段边界：最终树中的生成链接可导航，但未证明的来源不获得写地址；笔记片段转换依赖同版本完整语义标签集，资源片段转换依赖实际读取器对精确资源修订给出的资格证明。媒体区域必须通过实际授权资源的 `ResourceFacts` 核对页面、像素、提取产品及时间基准。此 crate 不提供媒体解码器、批注媒体 UI、OCR 或任意格式导入。不能精确保留的 JSON 数值会拒绝可写解码并保留原件。模板登记设置及源文件读取依赖必须由 Core 冻结，实例化复用同一复制规划并在真实未来目标编译。每个复制输入内一个来源只能使用一个结果身份；多实例由宿主分别限定来源／结果映射后合并冻结效果。`preserved_originals` 必须作为真实 Core 效果保存，不能仅展示损失后丢弃原件。

验证入口：

```text
cargo fmt -p weftext-knowledge --check
cargo test -p weftext-knowledge
cargo clippy -p weftext-knowledge --all-targets -- -D warnings
```

算法回归覆盖地址往返、移动／撤权／部分扫描、原生绑定遮蔽、隐式显示文字、嵌套交叉候选、组合／ZWJ 字素、损坏 JSON、私密前像隔离、伪造连续映射、建议双文件规划、媒体坐标资格、互相引用、定义键、current／pinned 复制以及模板输入注入。通过这些纯算法测试不等于桌面全流程、存储故障、权限服务或媒体交互已经验收。
