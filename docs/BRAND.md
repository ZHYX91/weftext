# Brand assets

Weftext retains its established ancient-Chinese 文-inspired mark with blue-black `#07172D` and warm-paper `#F4EFE4`. It is not a strict reproduction of a particular oracle-bone glyph. Technical restructuring and small-size adaptation must not replace it with W or a placeholder.

The [principal mark](../brand/logo-mark.svg) and [application icon](../brand/app-icon.svg) are original SVGs explicitly imported from the project's retained brand originals. Their path strings are preserved verbatim and share the same `evenodd` principal path. The principal mark uses `currentColor`: blue-black on light backgrounds and warm paper on dark backgrounds. The application icon retains its rounded background and transparent outer corners. Private historical records were not imported into the product repository.

The application icon is the source for delivered resources:

- The [generator](../packaging/windows/generate_assets.py) uses only Python's standard library. It renders the original straight-line path with even-odd filling and the rounded rectangle using 4×4 subpixel RGBA sampling. Unsupported path commands or structure fail rather than approximating a redesign.
- The Windows [asset directory](../packaging/windows/assets) contains 50, 150 and 44 pixel PNGs and an ICO with 32, 16, 48 and 256 pixel frames. Its first frame is 32 pixels, matching the current tray loading size. Executable build resources and tray reference the same ICO; packaging copies the same resources, with a matching blue-black MSIX background.
- The WebUI [copy](../app/public/brand/app-icon.svg) is generated byte-for-byte from the source, copied by Vite into dist and served by the application's static asset handler. The ordinary home/sidebar, hosted header and favicons in all three ordinary/hosted/Capture HTML entries use it.

Run `python packaging/windows/generate_assets.py` to update derived resources. `--check` compares decoded PNG content and the ICO directory/frames, avoiding false changes caused by compression bytes from different zlib runtimes. `python scripts/check.py` includes asset consistency. `python scripts/test_brand_assets.py` verifies equivalent compression, corruption rejection and actual consumer references; it also runs in the existing `scripts/mvp.py check` group. For frontend changes, also run `npm --prefix app run build`.

Actual small-size, transparent-corner and light/dark-background renders establish only the appearance of these resources. Static references and generation checks do not replace actual window/tray, OS scaling, installation/upgrade or whole-version acceptance of a new executable. Record those within the candidate boundaries in [WORKFLOW](WORKFLOW.md) and [PACKAGING](PACKAGING.md).
