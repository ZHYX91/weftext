# 公开文档术语表

本文统一 Weftext 公开文档中的中英文术语。它服务于可读性，不替代规范中定义的类型、字段和诊断代码。代码标识、文件名、产品组件名和界面中尚未本地化的命令保持原样。

## 产品与界面

| 英文概念 | 推荐中文 | 使用说明 |
| --- | --- | --- |
| workspace | 工作区 | 不使用“工作空间” |
| managed node | 受管节点 | 指由 Weftext 格式和 Core 管理的目录节点 |
| unmanaged content | 非受管内容 | 可见但不参与节点语义的文件或目录 |
| source text | 源文本 | 指作者保存的精确文档文本 |
| product surface | 产品端、产品界面 | 根据语境选择，不使用“产品表面” |
| UI surface | 界面、操作界面 | 不使用“表面”直译 |
| syntax surface | 语法形式 | 指作者可以书写的语法 |
| Inspector | 检查器 | 保留英文产品名时写作 Inspector（检查器） |
| ribbon | 功能区 | 指编辑器顶部按任务组织的选项卡区域 |

## 存储与安全

| 英文概念 | 推荐中文 | 使用说明 |
| --- | --- | --- |
| authority | 权威、权威源 | 表示最终裁决来源，不译为“权限” |
| authorization | 授权 | 与 authority 区分 |
| envelope | 元数据封装 | 指文档中的受保护系统元数据范围 |
| sidecar | 伴随文件 | 指与主文档相邻并由角色限定的文件 |
| inventory | 清单、盘点 | 文件集合用“清单”，执行动作可用“盘点” |
| payload | 载荷 | 指事务或回收站项目携带的完整内容 |
| fail closed | 安全拒绝 | 无法证明安全或唯一含义时拒绝操作 |
| Trash | 回收站 | 产品功能名称；代码标识保持原样 |
| draft | 草稿 | 不使用“草案”描述编辑器未提交内容 |
| receipt | 回执 | 指提交、导入、备份或恢复的持久结果证据 |

## 编辑、数据与执行

| 英文概念 | 推荐中文 | 使用说明 |
| --- | --- | --- |
| native checklist | 原生待办项 | 指 AsciiDoc 正文中的轻量待办项 |
| task node | 任务节点 | 指具有持久节点身份的任务 |
| promotion | 提升 | 指把原生待办项转换为任务节点 |
| native table | 原生表格 | 指普通 AsciiDoc 表格 |
| multidimensional table | 多维表格 | 指带类型化记录和多种视图的表格节点 |
| record | 记录 | 多维表格中的行；不是节点 |
| worker | 工作进程 | 指受限的导入、OCR 或转换进程 |
| caller | 调用方 | 指 Desktop、WebUI、Server、CLI 或获准智能体 |
| actor | 操作者 | 指接受授权、发起操作并被审计归因的人或服务身份 |
| participant | 参与者 | 仅用于批注会话、协作成员或在线状态等协作语境 |
| agent | 智能体 | 指 AI 智能体；网络语境中的 proxy 仍译为“代理” |
| profile | 规范配置、配置档 | 依据语境选择，避免与普通配置文件混淆 |
| projection | 投影 | 指从权威内容派生、可重建的结果 |

## 写作规则

- 第一次出现少见技术概念时，用一句普通语言说明它对用户的影响。
- 区分已实现基础、已确定但仍在实现的产品契约和尚未满足的发布门槛。
- 用户指南采用任务和结果导向；规范采用可验证的约束语言。
- 优先使用短句和分段。一个段落只承担一个主要论点。
- 中文和英文表达相同含义，但不要求逐字或逐句直译。
- 公开文档只描述当前契约和当前状态，不保存研究比较、内部排期或决策历史。
