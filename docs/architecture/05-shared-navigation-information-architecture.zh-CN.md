# 共享导航信息架构

桌面端和 Server WebUI 使用同一套导航语法。活动栏选择资源管理器、搜索或 Chrono；恢复、账户和设置是工具。资源管理器提供**层级**和**内容**。中央区域以编写、源代码或阅读方式显示活动受管文档，检查器承载大纲、属性、批注、反向链接和经授权的权限详情。

## 投影和打开

层级是完整的受管节点树。内容是在单一位置列出直接受管子节点，以及 Core 可见的非受管目录、非受管 Markdown 和资源。规范 `X/X.adoc` 仅由其节点行表示。被忽略内容绝不投影。

打开受管行会打开其 UUID。打开非受管目录只改变内容位置；不会创建节点标签页。非受管 Markdown 和资源在单独指定的共享操作允许更多能力前是只读清单行。仅因可见，它们绝不获得节点属性、Chrono、回收站、排序、批注、反向链接或修订检查的节点编辑。

## 权威和操作目标

层级和内容消费同一份 Core 清单以及 Core 派生的受管子节点顺序。客户端可以对可见类别分组，但不能自行重建排序或按文件系统路径分类。非受管行绝不参与节点排序。

一个共享解析器在激活时捕获不可变的类型化目标：当前节点命令使用焦点窗格节点，行命令使用显式行 UUID/项目 ID。计划、确认和提交均使用该捕获值。后续焦点、选择、刷新或虚拟化不能重定向操作。不可用、未授权或过期目标会显式失败。

## 状态、授权和无障碍

资源管理器模式、展开、滚动、筛选、宽度和非受管浏览位置都是设备本地的呈现状态。节点选择和文档历史以 UUID 为基础。使用分栏窗格时，焦点窗格定义当前节点；导航在替换窗格前必须保留草稿并遵守修订检查。

Server 在行、计数、面包屑、搜索结果、最近项目或事件到达浏览器前完成过滤。事件只是失效提示，不是权威。导航支持完整键盘操作，具有具名地标和正确的树/列表语义，并支持屏幕阅读器、高对比度、缩放、减少动态效果、RTL/混合文本、长名称、窄边栏和大工作区虚拟化。
