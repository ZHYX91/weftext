# 集合、Query 和派生视图

集合视图是一个规范 Query 结果上的、按权限过滤的派生视图；它们不创建权威数据库、不复制实体、也不改变身份。Query 契约由[架构 19](19-expression-query-and-template-library.zh-CN.md)及相应规范定义。看板和多维表格拥有各自独立的持久权威和适配器。

## Query 和多维表格边界

Query 视图可以是表格、列表、任务列表、看板、日历、时间线、画廊、图表或仪表板。`from` 选择显式源域；类型化 `scope` 定义经授权的总体；`view` 只是初始呈现提示。Core 拥有解析、类型、范围、授权、执行、排序、诊断和操作证据。客户端不能添加别名、字段、函数、隐式焦点或另一套求值器。

多维表格是一个受管节点，包含同质的表格本地 JSON 记录。一条记录不是一个节点。Query 结果使用“动态视图”这一术语；“多维表格”只用于已创作的记录数据。看板可以共享呈现基础设施，但保留源特定的类型化行身份和 Core 操作。

## 表达式、属性和编辑

`weftext.expr.v1` 有范围、确定、无副作用且可静态类型检查。它不能访问文件系统、网络、环境、环境时钟、随机、动态加载或 `eval`。Query 词法 `this` 是解析器拥有的嵌入上下文，绝不是 UI 焦点；时间只能经由显式上下文输入。

简单属性是有范围的字面文档头属性。除非版本化 schema 另有规定，自定义值均为可空字符串。编辑是狭窄的、修订绑定的 Core 操作。批量改动、拖拽、排期、关系改动、表单和多行编辑需要确定性计划、授权、预览、草稿门、可恢复提交和回执。Server 授权在交付前过滤行、字段、分组、计数、建议、诊断和导出。

## 模板库和数据界面

一个已配置的模板库根包含模板根和模板部件。它们仍是规范节点，但会从常规投影中排除，并通过模板库或显式模板 Query 域可见。模板根拥有 `weftext.template.json`；实例化创建带有新 UUID 的普通子树，通过已审阅映射重写内部链接、复制已拥有资源，并一次提交。

任务使用[架构 18](18-task-nodes-and-checklist-promotion.zh-CN.md)中的清单/任务节点并集。同质的已创作数据使用[架构 20](20-multidimensional-tables-and-editor-surfaces.zh-CN.md)中的多维表格 Profile。两者均不能以通用记录域的名义混入 Query。
