# PDF 导入和本地 OCR

PDF 适配器使用固定版本的本地 Lite 工作进程，并可选用经审查的增强。它执行文本提取、范围受限的栅格化、版式分析、本地 OCR 和表格重建，再将工作进程输出映射到 Weftext Import IR。工作进程 schema 绝不是 Core 或工作区权威。

## 打包和适配器边界

默认包只包含经审查的 PDF、版式、OCR、运行时、模型、词典和通知工件。可选能力必须单独打包、许可、固定版本并验收；模型下载必须显式，绝不能成为未披露的默认行为。工作进程没有环境网络访问。

```text
PDF 字节 -> 本地工作进程 -> 工作进程内部结果 -> PDF 适配器
-> 文缕 Import IR -> 已验证的 AsciiDoc 提案
```

适配器保留页面和边界框来源信息，在可用时先使用嵌入文本，并在证据需要时按页面/区域选择 OCR。保留原始 PDF 是一个显式的导入计划选项。

## OCR 和增强边界

识别 Profile 会针对混合 CJK/Latin、旋转、竖排文本、标点、表格和低分辨率扫描进行验证。一个模型覆盖只有在预处理、词典、张量、打包、许可证和质量共同验证后才受支持。

可选增强仅接收经批准的页面/区域证据和相关 IR 片段。它可以提议阅读顺序修复、标题/OCR 修正、表格重建、公式转写或插图描述。补丁绑定目标 ID 和基础 IR 修订；整篇文档替换、过期、超范围或无效补丁会被拒绝。

## 验收

语料库涵盖原生数字、扫描、混合、CJK/Latin、多栏、表格/插图密集、旋转、格式错误、加密、需要密码、大型和对抗性 PDF。证据分别报告语义质量、来源、内存、延迟、取消、清理、包大小、许可证通知和离线启动。
