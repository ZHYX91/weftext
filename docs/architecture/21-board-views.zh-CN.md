# 看板视图

看板是一个通用的派生呈现壳层，不是卡片数据库。Query 看板和多维表格看板只有在其类型化行身份和 Core 操作适配器允许时才共享泳道、卡片、虚拟化、选择和无障碍。看板持久性保留在源域中。

## 任务看板

任务看板按任务状态分组规范清单/任务节点并集。清单卡片只公开清单能力；任务节点卡片公开持久任务能力。移动泳道是源特定的 Core 操作：它修补精确清单标记、任务节点状态文档头，或已接受的表格记录字段。它绝不创建通用卡片/泳道权威，也不悄然提升清单。

添加卡片会创建一个具有显式活动父项和显式泳道状态的任务节点。添加简单清单仅在精确可编辑的文档出现项位置提供。卡片标题编辑因源而异；派生标题和计算字段只读。

## 排序和无障碍

横向拖拽只改变泳道字段。不引入泳道内持久手动排序：Query 使用规范 `order by`；表格看板使用类型化共享视图排序。占位符可做动画，但提交后必须返回派生顺序。

每次拖拽均有等效的菜单、键盘命令和无障碍状态选择器。桌面端/宽 WebUI 使用虚拟化泳道；窄布局使用无障碍泳道选择器和垂直卡片列表。Server 在卡片、泳道、计数、选择器值或诊断到达浏览器前完成过滤。

## 界面边界

看板通过动态视图或表格视图操作进入，并使用既有的数据上下文界面。它不增加永久看板权威、工作流引擎、看板特有评论/权限/自动化、泳道分组、隐藏排序或仅拖拽行为。
