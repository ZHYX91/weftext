## 7. Office 模板作者语法与 Mandatory §14 selector 修订

Office template 就是普通 DOCX/ODT/XLSX/ODS bytes。token 是可见文字。理解 binding 不依赖 content control、named range、Excel Table、hidden custom metadata、macro、formula rewrite、plugin 或 private mapping file。外层 brace 继续采用既有 exact ASCII-space 与 four-brace escape；replacement value 永不再次扫描。

simple binding 保留 `meta.title`、`meta.subtitle`、`header.NAME`、`node.id`、`field.FULL_FIELD_ID`、`content.body`、`view.bibliography`、`asset.NAME` 与 `data.SET.COLUMN`。若 native table 的 lowercase-ASCII leaf column 本身唯一，正向 spelling `data.native_table.amount` 保持。

本 A2 D9 候选**只具名替代 final FC §6.5.1 中 fresh-authoring 使用 hash token 的句子**。需要 qualification 或 leaf 非 ASCII/非 simple 时，fresh Office template bytes 使用以下可见 selector：

```text
{{ native.table[]::column["Amount"] }}
{{ native.table[]::column["Plan","Amount"] }}
{{ native.table["Budget"]::column["Plan","Amount"] }}
{{ native.table["Budget"]#0::column["Plan","Amount"]#1 }}
{{ native.table[null]#0::column["金额"]#0 }}
{{ ↓ native.table["预算 / A::B"]#0::column["实际","金额"]#0 }}
{{ → native.table["预算 / A::B"]#0::column["实际","金额"]#0 }}
```

bracket string 使用 JSON string-literal escape，解码后按 exact Unicode scalar sequence 比较；继续 normalization=none、case-sensitive、保留 whitespace。CJK、RTL、combining character、emoji、space、slash、double-colon、quote、bracket 因而都以用户可见文字存在，不变成 hash。occurrence suffix `#N` 是 canonical zero-based Counter text，只在前一级 exact title/path 仍碰撞时出现。`table[]` 表示不使用 table-title qualifier；`table[null]#N` 用 occurrence 限定无标题 table。column path 非空。

fresh compile 必须使用当前 frozen D2 table projection 中**最短唯一** selector：unique simple ASCII leaf → `data.native_table.COLUMN`；否则 shortest unique header suffix → 仍歧义才加 exact title → 仍歧义才加 table/column occurrence。0 candidate 为 mapping_required；用完允许 qualifier 后仍 >1 为 ambiguous_binding。后续加入碰撞对象会让 short token 在 fresh Plan 中变 ambiguous；already-frozen Plan 不变。

为兼容 Plan3，Core 仍可导出 FC 的 `nt_...` / `nc_...` ASCII key，作为 `nativeTableBindings` 的**内部编译 set/column key**并冻结 exact `D9NativeTableSelector/1`。这些 key 不再是 fresh qualified authoring spelling，也不能替换 Office template bytes 中的 visible token。真实 historical frozen Plan/Receipt 若使用旧 hash-token authoring，继续其 exact bytes/decoder。

同一 repeat band 的全部 token 必须解析到同一个真实 source table/rowset/order；band 内 ordinary sibling token 只能读该 SET 的 column。禁止逐 token 跨表拼行、hidden join、first-table、old-cache winner 或 opaque-ID shortcut。
