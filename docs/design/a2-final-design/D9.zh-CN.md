## 13. 图片尺寸、region 与 location

图片 physical size 只来自显式 source density fact，并使用精确有理数运算与 half-even micrometre rounding 计算。缺少 absolute density 时不得使用 72/96 DPI 或 viewport 默认值。relative density 只约束 display ratio。显式 output `imageSizes` 属于用户 layout policy，与 source physical fact 分离。

Import `SourceLocation` 中的源字节/页/单元格/部件坐标，与 Export 的 source_range/template_range 分属不同坐标域：source_range 使用 UTF-8 字节范围，template_range 使用 Unicode 标量范围，二者不可互换。

`RegionBody` / `d9rg1` 只表示 geometry。它冻结 profile 下已验证 page/rect，不含 author identity。外层 current D3 `ResourceRegionLocator/l1` 继续是完整 Resource/revision/geometry binding。Core 先通过 disclosure/currentness 和 authenticated production-version gate，再验证 region geometry 与 final barrier。equal bytes/geometry 不能恢复 stale revision authority。copy/fork 按原 D3 rule 重新签发 outer locator。

## 13a. Current Annotation Value/4 与 R6 consumer 边界
