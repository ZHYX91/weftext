# 写作、资料、查询与输出的完整使用流程

状态：设计修订候选，未实现；承接 [作者源](AUTHORING.zh-CN.md) 与现有 D1–D10。这里规定可观察交互与必要边界，组件样式和布局尺寸由实现验证。研究的功能名称不形成第二套领域模型；下列“纳入”表示纳入候选设计，不是产品已支持。

## 1. 共同规则

Desktop、WebUI、CLI 与获准 Agent 使用同一 Core；WebUI 的写入和下载经 Server 的当前授权。UI 按能力显示可执行动作和不可用原因，不能用无控件缩减合法 Source、用隐藏按钮代替鉴权或将预览称为保存。单一 Node + Field + Query + View + Action 复用到任务、数据库式表格、看板、日历和关系展示，不新增业务“数据库”或复制任务详情。

所有流程保留当前选区、未保存 Draft、Undo 与来源上下文；切换视图不自动提交。异步结果绑定原目标与操作，撤权/过期/更改 Base 后不能自动应用。个人布局、最近使用和面板排序是设备偏好，不修改文档作者顺序、Query 排序、共享权限或已经冻结的结果。

## 2. 写作与阅读上下文

从 Query 行、反链、搜索或批注打开来源时，可侧栏预览或分屏打开，同时保留原列表位置、筛选、选区和 Draft。返回时恢复界面上下文，再按当前授权重新取得内容，不能复活旧结果句柄。来源不存在、不可读或范围过期时分别显示状态，不猜测新锚点。

大纲支持标题过滤、当前位置、折叠、聚焦章节和返回全篇。沿用 D2 heading projection，支持原生和 Weftext 深标题、RTL 和无标题笔记；聚焦不删除/重排 source。专注模式与打字机滚动是独立开关；IME 组合、屏幕阅读器、键盘定位和用户主动滚动优先，不能每键抢焦点。Source 与渲染模式共享同一 Draft；不能准确映射时明确回到 Source，不以相同文字猜坐标。

个人“阅读/写作/复盘”布局只保存面板几何、选中的视图类型和可重新解析的导航目标，不保存权限、结果集、runtime selector 或替代 Draft。打开布局时重新授权和读取；不能打开的面板保留解释，未保存稿不随布局清理。跨设备同步布局和多人实时光标另行设计。

## 3. 快速记录与属性编辑

一个录入面板完成 parent、类型/模板、标题（可无）、业务属性和正文，创建前显示真实目标位置及必要冲突/缺失项。选择模板只产生 D9 准备结果；确认后才走原创建/安装流程。“保存并再记一条”仅在收到原保存结果后重置表单；网络 unknown 保留原请求和稿件，不自动创建第二份。快捷键不越过同一授权、预览或确认要求。成功后按原 resultAllocations 定位真实新 Node，重新授权打开并展示目标位置；不能以标题/文件名猜结果。在 Query 中录入并不保证新对象属于该集合：requireMembership 依原 D5 §19.3 在提交前验证；未要求 membership 时可成功创建且明确显示“不在当前筛选结果”，提供打开入口，不悄改 Query 或重建一份笔记。

属性面板可分组、搜索、固定常用字段；区分作者值、只读计算值与不可用值。简单字段用 [作者源](AUTHORING.zh-CN.md) 的原生表示，复杂值展开逐 occurrence 的备注/来源。用户可查看将写入的准确源码。显示标签和建议使用频次不是 FieldId；只有真实提交成功才更新设备最近使用，取消/悬停不计一次使用。身份只读，类型可按完整约束变更。

关系选择器显示获权候选及关系方向，选中后预览真实 Field/反向关系影响；不能只在客户端画一条线。汇总向导只构造现有 Query 投影，结果只读。基于已有 Facet/模板的内网录入表单复用本面板和 Core，仍由当前用户提交；匿名公开表单、代他人提交及跨对象多步宏不包含在本候选。

## 4. Query、任务与多维视图

列表搜索、可视化筛选与可选文本快捷语法生成同一 Query。Query 编辑器明确区分“哪些数据”和 View 的“如何显示”，提供可检查的定义、参数、范围与完整性状态。保存视图只保存原有 Document occurrence；不把当前结果写成第二份事实。保存搜索及 Trash 查询仍须解决原全局 P1，不能凭新 UI 宣称已经闭合。

任务是普通 Node 的 task 分类；详情是该笔记正文，status/due 等是原字段。任务表、智能清单、看板和日历都消费同一 Query/Field。勾选完成、拖看板卡片、修改截止日期要显示准确字段变化并走原 Action；没有可证明的唯一字段映射时禁止拖动提交，提供显式编辑。聚合行、只读值、隐藏目标、筛选变化后的旧行不能被当作可写对象。

查询示例覆盖未完成任务、按截止日期排序、关联项目、只读汇总和周期范围，明确空结果、缺值、错误、部分索引与真正完整结果。显示前 200 条不等于完整 membership；批量动作按原完整目标与预算，不静默拆批。查询语法不增加任意 JavaScript/SQL/Datalog 执行入口。

周期导航提供上一/下一/上级周期；日历点击先选择已有对象，明确“创建”才创建缺失笔记。沿用已有历法/周期/series-scope，不把当前日期/本地时区推断成新的作者值。规则预览显示输入日历、时区、范围与不可计算原因。提醒实际送达、稍后提醒、完成后重复、“我的一天”个人选集及自然语言日期解析分别后续设计，不能仅因存在 Calendar/Automation 就宣布具备这些能力。

## 5. 批注、引用与链接

音视频使用 D9-SCHEMAS §16 的准确有理 timebase/tick 半开区间签发，再按原 JSON Annotation 保存和导航；不是 wholemedia 替代。Annotation 读取包括已存摘要，不意味着可读隐藏目标媒体/正文；章节/Review Bundle context 仍独立授权。

阅读面板把“原文”“我的批注”“引用来源”连接起来。批注正文仍在独立 `weftext.annotations.json`；讨论状态与目标是否可解析分开显示。选择 PDF/图片区域→批注→显式插入引用→返回原区域复用 D3/D8/D9 原 region/source/权限规则；provider 缺失或坐标不匹配时保留批注和状态，不根据截图相似度换锚点。普通正文同样支持选择准确 document_range→记录想法/标记→按原 JSON Annotation 保存→返回原文。按章节/来源汇总只是当前获权 Annotation 的派生分组，不复制批注正文；失效、不可解析或不可读目标留在明确的未归组状态，原作者可获权的想法仍保留，不能显示隐藏原文。显式插入引用采用 §5.1 的完整 Source Draft 结构编辑资格，不把读取 adapter 当 writer。未保存批注稿按原 Draft 生命周期保留。

出链、入链、潜在提及三个集合分开。真正链接来自已解析的 source occurrence；潜在提及只是建议，不计入真实链接/图边/引用完整性。链接健康面板可诊断断目标、范围失效、无入链和孤立；“全库无入链”只能在获权且相关范围完整时成立，否则标明当前可见范围未找到，不泄漏隐藏节点数或自动清理所谓孤立对象。

### 5.1 正文潜在链接提示

设置为设备级“显示潜在链接”，默认关闭，可随时开关；关闭不改源码。第一版候选词来自当前获权 live Node 的原标题与已由 schema 识别的显式别名，不能从任意同名属性、历史/Trash/隐藏节点猜词。别名来源不可用则明确只扫描可用来源，不能声称完整。候选词去重保留完整 NodeRef，不按标题合并不同对象；默认排除当前 Node 自身。

匹配在 D2 具有准确 root-authored 可写来源的普通可见文本片段上进行，采用精确 Unicode scalar 字面匹配，不做模糊、大小写折叠或正规化。代码、公式、URL、现有链接、外来 front matter/属性值、批注、generated/include/multi-origin/passthrough 和不能证明可写范围的内容不加可转换提示；不跨两个文本片段拼词。匹配器产生绑定同一 Draft serial/flow 的完整 `[start,end)` Unicode scalar 区间；示例中的数字不是 UTF-8 byte offset。转换须经 fresh Draft map 换算为准确 D2 完整文件 byte/EOL 范围，owner、Base、draftSerial 和 source 必须一致，两端均为原 D8 Unicode18 grapheme 边界且不拆 CRLF。只命中展开字符或 grapheme 的一部分、或无法逆映射时，只保留发现及不可转换原因，不扩大选区。软换行可在同一逻辑片段中画线，source join/EOL 或两个片段不拼词；这不限制 schema codec 的合法 Unicode scalar 值。

相同范围的多个目标聚为一个提示组；不同范围即使嵌套或交叉也保留。例如“白云山”的 `[0,3)` 可列“白云山”及以此为别名的“白云山2026”，`山` 的 `[2,3)` 单独保留；“白云山南路”的 `[0,3)` 与 `[2,5)` 同时保留。悬停/键盘聚焦显示匹配文字、完整候选标题、可获权的路径/上下文和匹配原因；多目标必须由用户选择，不默认第一个。

初版视觉最多使用两条上下分离的提示线，已有真实链接保持原样式；重叠超过两条用统一密集提示及“更多匹配”入口，不无限向下堆线，也不只靠重合变色传意。线层分配按 start 升序、同 start 按 end 降序，给最小可用层；未能占层的组仍在弹层中，不丢弃语义匹配。跨行按实际文字片段画线，RTL 用逻辑 source range 与实际排版映射，不能按屏幕 x 坐标排序语义。触屏长按/动作菜单、键盘命令和可访问列表提供等价入口，悬停不是唯一操作。

普通点击打开候选选择/说明；明确“转换为链接”才修改 Draft，目标须再次通过当前授权和身份解析，原 source range 与文本必须仍准确。转换要求完整 Source 读写资格，不能把目标可读误当源可写；无此资格时明确不可用。UI 为同一 Draft 自动构造准确完整 proposed Source，使用 D2 原生 link/xref 与原 NodeRef 编码，经过同一 parser 完整重解析，证明新增 occurrence 指向所选完整 NodeRef 且可见文字、未选字节不变，然后进入原 Source 编辑的 prepare/save。D2 identity adapter 只验证解析投影，不是 writer；不得走禁止新 macro 的 d8_draft_text_replace/2 或 splice_plain 成功分支。包含方括号、逗号、引号或 role-like 内容的 label 必须按原生语法编码并重解析验证；不能证明等价时保留 Draft 并提供 Source 预览/修复，不声称转换成功。用户无需手写语法，也不生成第二种双链语法。弹层有明确的建议可访问名称，Escape 返回原选区，不抢键入焦点。一次转换是一个 Undo 单元；保存仍走原 D8/D6。ABA、输入变化、目标删除/改名、撤权、schema 改变使旧建议失效，重新计算而不自动换词；已有运行时 evidence 不复活。

扫描按可见区域优先且可取消，受原文档/工作预算约束，不阻塞打字。每个弹层先展示最多 20 个目标，再按稳定 NodeRef 顺序分页；高密度文档可停止装饰并显示扫描未完。截断/预算不足必须可见，不能把已显示匹配当全集；没有完整扫描也可以显式转换一个已完整获权验证的具体候选，不进行全局负断言。可重建候选索引随授权和名称/schema 变化失效，不能作为新的事实存储。

### 5.2 链接形式与转换

完整行为由 [LINKS](LINKS.zh-CN.md) 唯一拥有。右键/长按/键盘命令提供稳定 ID、源相对路径、库内完整路径与本机绝对路径的转换、复制地址/完整链接和最短有效相对路径。设备默认 ID 不重写既有源；库根地址明示 Workspace，不与本机盘根或普通相对路径混用。转换是同一完整 Source Draft 的一次 Undo，复制不改稿；目标/fragment/原生属性必须可证明保全，路径披露、不同形式未来移动行为和稳定身份边变化均可见。无损表达不了 fragment 时禁用该形式，不删锚点；通用离线导出路由尚须 D9 具名后续设计。

## 6. 模板、表格与输出

模板入口展示用途、参数、示例和真实输出预览；错误能回到原输入位置并给出可行动的下一步。生成、验证、准备发布、已发布与清理警告是不同状态。Worker 成功不等于作者保存成功。内网 server_download 在获权且确认原 ExportPlan/4 的同一 inputs/loss choices/staged bytes 后，按准确 dataFile 的受控文件名交付原 bytes；结果页显示 Server delivery state 和下载入口，不要求外部发布目录或 PublicationReceipt/4，也不要求用户访问服务器磁盘。下载 token 绑定原 Plan/确认/dataFile 和当前 audience，逐次及逐 chunk 重验授权与原保留期限；重试只续交仍保留的同一输出，过期明确不可用，用户重新生成须另行确认。外部 bundle 发布才消费原 PublicationReceipt/4，纯下载不得冒充原子文件发布。过期、撤权、下载中断和 unknown 原发布分别处理，不能静默重跑外部发布或重新生成不同文件。

原生表格提供可发现的已有行命令、准确 Source 编辑入口、未保存稿恢复、复制取出与明确丢弃。复杂合法表格没有对应控件时保留原文读写，不压平成缩水子集。批量范围粘贴、列级重排/生成和 HTML 富粘贴涉及新增转换规则，列为独立后续增量，不冒充本轮已有控件。

| 属性布局、快速录入、模板表单 | 纳入 §3 | 同一 Field/schema/Template/Core；无任意宏或匿名表单。 |
| 数据库式视图、智能清单、任务详情 | 纳入 §4 | 同一 Query/View/Action，原搜索 P1 未关闭。 |
| 周期导航、规则预览 | 纳入 §4 | 沿用已冻结历法；送达/稍后/完成后重复另议。 |
| 阅读批注、PDF 引用、出入链/链接健康 | 纳入 §5 | 复用 JSON Annotation/Region；跨权限完整性不可省。 |
| 可选潜在链接与重叠 UI | 纳入 §5.1 | 可取消派生建议，显式转真链；不产生假图边。 |
| 链接四形式、转换与复制 | 纳入 §5.2 / LINKS | 原生语法与同目标验证；新 ID+anchor、通用离线路由明确后置。 |

七组自有插件的设计输入分别落到内容/结构边界、常用字段与提交后偏好、周期导航、链接诊断与潜在提示、原生编号与标题、表格操作与恢复、转换任务状态与输出体验。只吸收设计，不迁移宿主私有存储或 runtime。调研事实与取舍依据保留在独立研究记录，不作为产品已支持声明。


## 8. 设计验收

所有 UX 案例均为设计要求，产品 UNRUN：UX-01 侧栏打开/返回保留 Draft，撤权不返旧内容；UX-02 IME/RTL/屏幕阅读器与聚焦/打字机共存；UX-03 unknown 保存后再次录入不重复创建；UX-04 属性转换无损并保留无关 source；UX-05 表/板/历编辑同一任务且只读/聚合行不误写；UX-06 不完整查询不冒全集；UX-07 周期点击不自动创建；UX-08 批注目标失效不丢讨论；UX-09 隐藏反链不泄漏；UX-10 同范围多目标、嵌套与交叉重叠均可选；UX-11 超两层和超 20 目标、键盘/触屏/RTL 仍完整可达；UX-12 stale/撤权/已有链接/生成文本不误转；UX-13 显式转换/撤销/保存只有一个原操作；UX-14 导出失败/unknown/过期下载不伪装成功；UX-15 合法复杂表格 Source 保全；UX-16 本地布局不覆盖 Draft/共享作者顺序或恢复旧权限。UX-03 还覆盖创建成功但不属于当前 Query 的准确定位；UX-08 覆盖普通正文批注及章节汇总失效不丢想法；UX-12 覆盖 e 加 combining mark、emoji ZWJ、中文 scalar 与 UTF-8/UTF-16 坐标差异；UX-13 覆盖全源资格、原生 label 编码与完整重解析，禁止借窄文本入口注入 macro；UX-14 覆盖没有外部发布目录/receipt 的纯下载及准确 dataFile 重试。

UX-17 覆盖四种链接形式、库整体迁址、同名/跨库/本机与服务器边界、转换/复制/Undo 和准确 fragment；具体正反例为 LINK-01–11。UX-18 覆盖任务属性组来自 FacetSchema 而非源嵌套、共享 Field 不复制、默认链接设置和折叠偏好不改现有源。
