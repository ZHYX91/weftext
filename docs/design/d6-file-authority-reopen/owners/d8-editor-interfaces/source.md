### 8.3 Ordinary-writing closed loop

For E=LF/CRLF/CR and Arabic/Hebrew/mixed text, the full trace includes:

2. Delete م from `= T\n\nم `, yielding exactly `= T\n\n ` with no paragraph and plain caret offset0. Preserve the space; typing ש next yields `ש `.
3. Enter inserts two EOLs. Further Enter, spaces/tabs, and per-EOL Backspace/Delete traverse multiline-paragraph and single-line states. Reopening the current Draft still supports these operations without treating historical Undo as deletion.
4. Splitting around whitespace, reverse selections, blank-line deletion, and merging preserve unselected whitespace/mixed EOLs. Emptying a region returns plain/site for first typing again. Every Undo/Redo assigns a new serial/projection.
5. Queues accept only the transaction's exact binding/next serial. Late A cannot overwrite later native B; composition cannot prepare. Only actual D8 prepare, complete D7 effects, explicit confirmation, and original D6 receipt establish author submission.
