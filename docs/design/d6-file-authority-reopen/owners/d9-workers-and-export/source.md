## 1. Providers, routes, and capabilities

A Provider is a concrete executable adapter reviewed for installation, version, dependencies, license, and sandboxing. A Route is a finite ordered acyclic pipeline; every step fixes Provider/version, input-format profile, output profile, options, and budget. Filenames cannot select arbitrary programs, download dependencies, execute shell commands, or invoke unplanned fallbacks. OFD→PDF→page IR must declare both steps and both losses while retaining original OFD; intermediate PDF is not the original.

Registry is host installation configuration, not worker output, template content, or editable workspace text. routeId/profileId are ASCII `[a-z][a-z0-9_.-]{0,63}` matching unique reviewed records; record updates invalidate old unfinished preparation. Each record names executable/dependency versions, platform/architecture, argument schema, exact input variants, output types, resource limits, isolation evidence, license/distribution disposition, and format-corpus tests. All D1 capability rules must hold for available; any missing condition means unavailable. Provider claims, extensions, and exit0 do not establish qualification.

First-generation input-profile/probe-variant mapping is unique: pdf_page_v1→pdf/pdf; image_page_v1→image/png or jpeg; csv_utf8_v1→csv/utf8; tsv_utf8_v1→tsv/utf8; xlsx_grid_v1→xlsx/transitional; ods_grid_v1→ods/odf13; docx_flow_v1→docx/transitional; odt_flow_v1→odt/odf13; xps_page_v1→xps/xps2005; oxps_page_v1→oxps/openxps2009; ofd_page_v1→ofd/gbt33190_2016. Recognition is not availability; Strict OOXML, new ODF versions, and multiframe TIFF need separate profiles. Reject malicious disguises, mixed packages, or unknown versions without silent downgrade.

## 2. Isolated execution and untrusted input

All probing, parsing, OCR, rendering, and template compilation treat files as untrusted execution inputs, including “pure Rust” Providers. Trusted host performs only bounded raw copying, isolation startup, and structural/budget checks. Full format parsing stays outside the author-transaction process. Workers see no workspace mount, author DB, home directory, browser profile, SSH/API credentials, environment secrets, system clipboard, or network. Expose only this job's read-only input slots, reviewed read-only dependencies/fonts/models, and private output/temp directories, without inherited extra handles. stdout is bounded protocol only; stderr is bounded and redacted.

Windows must prove restricted identity/AppContainer or equivalent isolation, ACLs, denied network, controlled process trees, and Job Object limits; memory limits alone prove no file/network restriction. Linux must prove read-only mounts, separate namespaces, denied network, seccomp/equivalent syscall policy, cgroups, and process-tree cleanup. A container name or timeout is insufficient. Missing host evidence yields provider_unavailable, without a “trusted user file” bypass.

ZIP/OPC/ODF inputs limit compressed/expanded bytes, entry counts, nesting, compression ratios, and XML nodes/text both before and during streaming extraction. Reject absolute/traversing/encoding-aliased paths, duplicate canonical part names, symlinks/hardlinks/devices/reparse points, overlapping entries, encryption/unknown algorithms, DTD/entity/network parsing, and cyclic relationships. Charge expanded ODF repeated rows/cells; one XML element cannot evade million-cell costs. Detect/report external relationships without fetching. Active content may prevent conversion but never executes; Office templates reject it under Templates. Original attachments stay inert bytes and preview uses separate safe profiles.

Internal closed WorkerInvocation/1: `{version:1,jobToken,step,routeId,routeRevision,profileId,inputs,options,budget}`. inputs is `{slot,byteLength,sha256}` array with host-assigned slots. Step is Counter; routeRevision is a host-issued D6 Token. Host records bind job/route/input/audience; worker may echo only equal values. No path/URI/executable/command member exists. Startup configures process I/O handles by slot, not JSON. Budget directly reuses D6 BudgetBinding; all steps consume one cumulative job budget without per-step resets.

Terminal results are `{version:1,jobToken,step,status:"ok",resultSlot,outputSlots}` or `{version:1,jobToken,step,status:"failed",code}`, code only `unsupported|encrypted|unsafe|malformed|budget|cancelled|internal`. Nonzero exit, signal, timeout, truncated protocol, extra stdout, or missing result all fail without partial IR. resultSlot contains complete IR or the route's declared next-step format. outputSlots elements are `{slot,byteLength,sha256}`; slots are unique and real files regular/unaliased. Host rejects undeclared extras and rereads actual bytes for comparison. Worker cannot write permissions, loss choices, identity, receipts, or published flags.

Completely validate IR, format coverage, losses, and budget before immutable pinning. Valid bytes do not prove correct extraction; independent validators/corpora gate profile enablement. Parsed text/formulas/headers/HTML/errors never become commands, executable templates, or HTML. Output remains in its generation directory until host validation; workers cannot rename to final paths.

After crash/timeout/cancellation, host first terminates and confirms exit of the complete process tree, then cleans unpinned staging; author store is unchanged. Unconfirmed kill seals off the directory and disables the route; never reuse output still writable by a process. Retries require identical inputs/versions/budget and explicit remaining allowance. Automatic retries are bounded and cumulatively charged; exhaustion fails. No infinite fallback or route substitution as the same result. Cleanup never deletes source files or committed receipts.
