## 2. 技术成员归属和受控范围

`wireVersion,kind,operationId,workspaceRef,expectedAuthorityToken`为继承的协议基础成员；D6自己的discriminator全部在表中。`Counter,Uuid,Token`为接口文档局部类型别名，不是新公共概念；Token承载各自concept已登记的plan/effects/result/cursor，tag不可互换。`commitSequence,contentSequence,revision,configurationRevision,expectedConfiguration,expectedRangeRevision,expectedPolicyRevision,expectedResourcePolicyRevision,targetOperationId,targetProtocolOwner,increment,seriesScope,targetMultiplicity`为上述概念下的局部schema成员，须按所属接口exact拼写；不得独立发布裸通用Revision或Owner概念。`policy_admin`和其他capability、`allow/deny`与各scope discriminator是Control Commit Protocol的封闭policy schema技术枚举，不形成用户角色名。BudgetBinding全部max*字段由Budget Binding唯一拥有；PrincipalContext的session/delegation等仅内部认证映射。

接口§2–14列出的其余闭合member和error/state/enum均为上述所属对象的局部技术投影，实施schema必须从该完整接口建立逐成员索引，不允许同一schema member在不同对象被赋予相反语义。本文件机器注册表拥有公共概念/导出/discriminator/locale，接口拥有各closed对象的精确成员集合，两者共同作为生成输入；不将每一个内部局部变量抬升为产品概念。

## 3. 碰撞、迁移和负向门禁

Storage Domain / Workspace / Authority分别是物理原子域、内容identity namespace及D3解释权；Source Version / Storage Fence / authority generation / policy revision / result epoch分别比较，不能复用一个version。Prepared Intent / D3 planned / commit decision不同；plan token、完整result handle、D7行选择器不同。Field Value Occurrence / Document Occurrence / Entity不混称Record。Source Checkout / ordinary import / copy / promote / subscribe / sync沿用D3/D4/D5动作边界。D6不创建DocumentRef、RecordRef、FieldRef、EntryRef、ViewRef、ResultRef或StorageDomainRef。

Profile、Field/Attribute、Relation/Node Link/Typed Reference/Citation、Resource/attachment、Time/Calendar、Library/Work、owner/authority/source/provenance/origin及Template/Preset等Mandatory §8.5碰撞组导入D3/D4/D5已有裁决；plugin/extension/module/pack/connector与D7/D8/D9/D10新增名继续由对应阶段冻结，不在本阶段造别名。D6只引入本表明确的storage/control限定语。

负向扫描只针对本候选注册表、接口discriminator、公共code exports、schema/locale及实施适配映射。测试必须拒绝重复concept ID、重复owned name、重复locale key、未登记d6_*入口、表/机器注册表漂移、故意拼错owned name/locale；同时普通用户正文、引述反例、历史review和迁移说明的同词不报错。旧原型的显式alias清单、warning兼容期和迁移截止只能在对应实施切片据真实导出确定；本候选没有引入可继续发布的alias，不虚构已发布兼容承诺。

管理准备和控制读取的新增d6_* discriminator分别归Prepared Intent和Control Inspection Protocol；绑定退役显式归Binding Retirement Intent，compareForeignVersion保持纯读取。Source Checkout的完整拒绝别名为`D6Record-as-entity`、`unqualified-source-as-origin`，普通记录/来源字词不在受控标识符之外禁止。

跨阶段承接必须从D1–D5消费者反查，不只扫描D6自身Interface。机器表crossStageBindings保留D2/D3/D4外形归属；DocumentRevision等类型映射不新增随机Token域。ByteHandle与ByteReadProtocol分别归资源字节句柄及其closed读取协议；d6_byte_handle两成员外形仍由D2引用，payload/current authorization由D6定义。上传staging与损坏Document repair envelope不属于资源ByteHandle。
