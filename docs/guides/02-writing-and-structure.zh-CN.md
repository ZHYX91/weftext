# 写作与文档结构

## 三种文档视图

Weftext 围绕同一份精确 AsciiDoc 源文本提供三种视图：

- **Write** 用可视化命令编辑内容和结构。
- **Source** 显示并编辑精确源文本。
- **Read** 提供安全、不可编辑的渲染结果。

切换视图不会创建第二份文档。所有变更都必须通过 Core 生成受修订约束的精确源文本操作；界面不会靠拼接标记或修改渲染后的 HTML 来保存内容。

## 功能区与快捷入口

**已确定设计：**顶部功能区包含六个固定选项卡：开始、插入、数据、引用、审阅和查看。表格、图片、动态视图、任务和模板设计等上下文选项卡只在选择相应内容时出现。

同一动作也可以出现在上下文菜单、选择浮层、斜杠菜单、命令面板和键盘快捷键中。它们共享同一动作定义，因此右键不会成为唯一入口。

格式刷复制的是语义格式，不是 CSS、HTML 或任意源文本。单击应用一次，双击可连续应用，`Escape` 取消。它不会复制文字、链接目标、节点身份、任务状态、批注或资源路径。

## 标题和文档标题

文档标题和可选副标题属于文档头，不是正文标题级别。正文使用 H1–H9 选择器。修改标题级别时，用户可以只修改当前标题，也可以在合法范围内保持整棵子树的相对层级；可能重组大纲的操作会先显示预览。

Query 中的 `this.heading` 只表示当前正文位置所属的最近标题。文档只有标题、光标位于前言，或当前位置不属于任何正文标题时，它为 null；它不会退回到文档标题。

## 表格和图片

原生表格支持选择前 N 行或列作为表头、矩形合并、拆分、插入或删除行列，以及设置题注。合并多个非空单元格前必须预览内容组合，避免静默丢失数据。

图片首先作为节点附件安全导入，再写入规范引用。导入失败不能留下半完成的源文本或孤立资源。独立文件模式只能使用作者明确选择的相对路径，不会获得节点资源所有权。

## 当前状态

**当前基础：**精确修订、保留源文本的编辑计划、Write/Source/Read 模型、共享导航和 Windows 桌面 Alpha 已有实现基础。

**发布前限制：**完整功能区、所有格式命令、表格结构编辑、图片工作流、格式刷、可访问性和输入法验收仍需在打包应用中完成。界面中出现设计入口不等于对应能力已经通过发布验收。
