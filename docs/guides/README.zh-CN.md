# Weftext 用户指南

这里用普通语言介绍 Weftext 的核心概念和已确定的使用方式。Weftext 仍处于发布前阶段，因此每一页都区分当前基础、已确定设计和发布前限制。指南不把设计目标表述成已经交付的功能。

规范和架构文档仍是实现契约的权威。如果本指南与更新后的规范冲突，以[规范索引](../README.zh-CN.md)为准。

## 从这里开始

1. [工作区、节点与附件](01-workspaces-nodes-and-files.zh-CN.md)：了解内容如何保存，以及普通文件如何成为附件。
2. [写作与文档结构](02-writing-and-structure.zh-CN.md)：了解编辑器、标题、表格、图片和独立 AsciiDoc 模式。
3. [待办、Query 与模板](03-tasks-query-and-templates.zh-CN.md)：了解轻量待办项、任务节点、集合视图和模板库。
4. [多维表格与看板](04-tables-and-boards.zh-CN.md)：了解记录、视图、原生表格升级和看板操作。
5. [历史、备份与导入](05-history-backup-and-import.zh-CN.md)：了解设备历史、正式备份、比较恢复和外部格式导入。

## 状态标签

- **当前基础**：仓库和产品原型中已经存在、可以由当前实现证据支持的能力。
- **已确定设计**：公开规范已经确定，但完整产品实现和发布验收仍在进行。
- **发布前限制**：在公开发布前仍然不可依赖或不应对外部署的能力。
